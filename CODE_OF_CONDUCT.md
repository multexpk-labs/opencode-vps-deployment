# Code of Conduct

This project is intended to be a technical learning and collaboration space.

## Expected behavior

Participants should:

- communicate respectfully;
- focus criticism on technical ideas and evidence;
- provide reproducible details when reporting problems;
- respect licenses and project attribution;
- avoid sharing secrets or private information.

## Unacceptable behavior

Do not use the project for:

- harassment;
- threats;
- discrimination;
- deliberate disruption;
- publishing credentials or private data;
- malicious deployment instructions.

Maintainers may remove content or restrict participation when necessary to keep the project usable and safe.
