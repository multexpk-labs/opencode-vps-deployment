# Contributing

Contributions are welcome when they improve the technical value, correctness, or clarity of the repository.

## Useful contributions

- Fix incorrect commands.
- Improve explanations.
- Add reproducible deployment examples.
- Document new AI infrastructure patterns.
- Add research methodology or benchmark results.
- Report outdated provider information.
- Improve security guidance.

## Before opening a change

1. Check existing documentation.
2. Keep examples generic and sanitized.
3. Never commit passwords, API keys, tokens, private keys, customer data, or private infrastructure details.
4. Test commands where practical.
5. Explain assumptions and version-specific behavior.

## Research contributions

For benchmarks, include:

- date;
- model/version;
- runtime;
- hardware;
- relevant configuration;
- workload;
- measurement method;
- limitations.

## Documentation style

Prefer:

- one clear topic per section;
- short paragraphs;
- copyable commands;
- placeholders such as `CHANGE_ME`;
- links to authoritative upstream documentation.

See [SECURITY.md](SECURITY.md) before reporting a security issue.
