# Roadmap

This repository is intended to grow as a practical AI infrastructure and VPS education project.

## Current areas

- OpenCode VPS deployment
- Linux and VPS administration
- Nginx reverse proxy
- Cloudflare
- Docker
- Ollama
- AI gateways
- LLM research methodology
- AI agent architecture
- security and backups

## Planned areas

- more reproducible AI experiments;
- model evaluation templates;
- GPU/VRAM planning guides;
- inference benchmarking;
- monitoring examples;
- automation patterns;
- MCP deployment examples;
- production incident lessons;
- community contributions.

## Research policy

New research should record its date, environment, assumptions, and limitations. Provider-specific information should be rechecked when it becomes operationally important.

## Community

Issues and pull requests can be used to propose documentation improvements, report errors, and share reproducible findings.
