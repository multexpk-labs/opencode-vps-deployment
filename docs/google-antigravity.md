# Google Antigravity Free Models

Google Antigravity provides an AI coding/agent environment with a model selector. Availability depends on the current plan and Google can change the available models and quotas.

The official model documentation currently lists free-plan access to reasoning models including Gemini variants, Claude thinking variants and GPT-OSS-120b.

## Practical workflow

1. Install Google Antigravity from the official site.
2. Sign in with the Google account being used for the free plan.
3. Open the model selector.
4. Select an available free model.
5. Check the current usage/quota indicators before long agent runs.

## Important

Do not document a model as permanently free. Free-plan availability, limits and model names can change.

Antigravity is a hosted service. Do not assume that using a free model provides the same privacy characteristics as a local Ollama model.
