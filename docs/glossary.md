# AI Infrastructure Glossary

## AI agent

A software system that uses a model plus tools, context, and an execution loop to perform tasks.

## API gateway

A service that receives API requests and can route, authenticate, transform, observe, or forward them.

## Context window

The amount of model input and output context a model/runtime can process within a request.

## GGUF

A model file format commonly used by local inference tooling.

## Inference

The process of running a trained model to produce outputs.

## LLM

Large language model.

## MCP

Model Context Protocol, a protocol used to connect AI applications with external tools and context providers.

## Quantization

A technique that represents model weights with lower numerical precision to reduce memory requirements and potentially change performance characteristics.

## Reverse proxy

A server such as Nginx that receives client requests and forwards them to an upstream application.

## Token

A unit of text processed by a language model. Tokenization differs between models.

## VPS

Virtual private server: a virtualized server environment with allocated compute, memory, storage, and networking.

## WebSocket

A persistent bidirectional connection often used by interactive web applications.
