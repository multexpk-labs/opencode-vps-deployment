# Production Projects

Before an agent modifies a production project:

1. Inspect the repository and run `git status`.
2. Read project instructions such as AGENTS.md.
3. Back up important data.
4. Review the intended scope.
5. Make small changes.
6. Run appropriate tests/checks.
7. Review `git diff`.
8. Commit or deploy only when explicitly intended.

Do not place credentials in source control or make unrelated server-wide changes.
