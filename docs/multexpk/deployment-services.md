## Typical deployment workflow

1. Requirements review
2. Server and operating-system preparation
3. Network and firewall configuration
4. Application deployment
5. Reverse proxy and TLS
6. Authentication and secrets
7. Monitoring
8. Backup and recovery planning
9. Testing and handover

## Why document deployments?

A documented deployment is easier to:

- reproduce;
- troubleshoot;
- migrate;
- audit;
- maintain;
- hand over to another engineer.
