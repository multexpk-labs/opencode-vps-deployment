## AI-focused VPS use cases

A suitable VPS can host:

- OpenCode and AI coding agents
- Ollama and self-hosted model runtimes
- AI gateways and OpenAI-compatible APIs
- Docker-based development environments
- n8n and automation workloads
- private development servers
- web applications and APIs
- testing and research environments

The required resources depend on the workload. CPU-only applications and GPU inference have very different requirements.

## Why use a dedicated environment?

An isolated server can provide:

- persistent project storage;
- predictable network access;
- long-running services;
- custom software installation;
- private development environments;
- control over firewall and reverse-proxy configuration.

## Before choosing a VPS

Define:

1. CPU requirement
2. RAM requirement
3. GPU/VRAM requirement, if any
4. storage requirement
5. bandwidth requirement
6. operating system
7. required ports
8. backup requirement
9. expected concurrency

Do not choose a configuration from a model name alone. Benchmark the actual workload.
